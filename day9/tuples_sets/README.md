## Part A:- Product Analytics System:- 
This is a product analytics system implemented in Python. It analyzes a set of customer carts and product catalogs to provide insights such as bestsellers, exclusive purchases, and catalog reach. The system uses namedtuples and sets to efficiently process and analyze the data.


### Files:- 

[`product_analytics.py`](./product_analytics.py): main program containing product analytics logic


## Part B:- Bundle Discounts System:- 
This is a bundle discounts system implemented in Python. It uses frozensets to efficiently process and analyze the data. The system takes a set of customer carts and product catalogs as input and provides insights such as best bundle discounts, matching bundles, and bundle discount percentages.

### Files:- 

[`frozenset_bundles.py`](./frozenset_bundles.py): main program containing bundle discounts logic 

### How to use:-
