## Part A:- Student Analytics System:- 
This is a student analytics system implemented in Python. It analyzes a set of student records and provides insights such as 
GPA, top performers, student reports, and student classification.
### Files:- 

[`student_analytics.py`](./student_management/student_analytics.py): main program containing student analytics logic 

[`test_analytics.py`](./student_management/test_analytics.py): test script for student analytics



### How to use:- 

1. Move into student_management directory 

```bash
cd student_management
```

1. Run the program using :-

```bash
python3 student_analytics.py
```

```bash
python3 test_analytics.py
```
